# 深入·局域网互传

同一个网络，聊几句，传点东西。深色玻璃界面、原图分享与大文件续传。

当前发布版本：**1.0.0**。

## 下载与使用

在 [Releases](https://github.com/toggerdemetri-lgtm/shenru-lan-transfer/releases) 下载 Windows 或 Mac 安装包，完整解压后打开 EXE / APP。无需自行安装 Node.js。

1. 同一局域网内，一人先启动应用提供服务，其他人可启动应用加入，或使用主机生成的 HTML 入口。
2. 等启动完成，把同目录更新后的“深入·局域网互传.html”发给朋友；朋友打开后进入同一个空间。
3. 在“我的好友”的在线邻居中添加朋友，对方同意后即可聊天、分享原图与文件。

Windows 10/11 x64 使用系统托盘，Mac 使用顶部菜单栏。关闭网页后服务仍在后台；退出主机会结束当前空间。更新前先从旧版托盘或菜单栏退出，再启动新版并重发更新后的 HTML。

Mac 包同时包含 Apple Silicon 与 Intel 运行时，自动选择架构，要求 macOS 13.5+。当前 Mac 构建未签名、未公证，尚未完成 Mac 实机验收；包内保留完整说明。

## 功能

- 在线邻居、好友码、好友申请与即时聊天，昵称和好友关系持久保存。
- 单文件最高 10GB，支持多文件队列、拖拽、粘贴图片、暂停、继续与断线重试。
- 刷新后重选原文件继续传输；分块认证与最终 SHA-256 校验。
- 原图不压缩，点击空白关闭预览，下载保留原文件内容及名称。
- 实时速度、已用时间、预计剩余与完成提醒；系统通知需要浏览器支持并授权。
- 批量下载新增文件、重新下载本批、已下载状态与重新下载入口。
- 上翻阅读时，输入框上方显示新消息胶囊，点击回到最新。
- 常见 TUN / VPN / 虚拟机网卡地址作为备用，默认优先选择实际局域网地址。

Windows、Mac 与手机浏览器须处在可以互相访问的同一局域网。默认 TCP 3000、UDP 42376；路由器隔离、防火墙或移动网络可能影响连接。网页服务不面向公网部署。

## 内容加密与数据

浏览器自动使用 X25519、HKDF-SHA256 与 XChaCha20-Poly1305 处理聊天和文件内容，保持现有操作；私钥留在当前浏览器，服务正常运行时不保存内容明文。

**当前没有 HTTPS，也没有人工核对首次公钥身份。** HTTP 页面可被主动攻击者替换，不等于经过审计、验证身份的可靠端到端通信。文件名、大小、类型、昵称、关系和流量元数据仍可见。请在可信局域网使用，详见 [加密说明](docs/content-encryption.txt)。

昵称和好友关系由主机保存。双方离线满五分钟后清理临时聊天与文件，好友保留；重启主机会清除临时会话。刷新续传需要重选原文件。浏览器“已下载”表示校验后已交给浏览器保存，不能确认最终系统写盘；首次批量下载可能需要允许多个文件下载。

仓库不包含身份数据库、聊天内容、传输文件、浏览器私钥、开发者测试数据或原始设计工程。

## 从源码运行

需要 Node.js 24 或更新版本。应用依赖的浏览器端库已经随源码附带，无需安装 npm 依赖。

```sh
node server.mjs
```

使用终端显示的局域网地址访问。开发模式数据写入项目 `.data/`，已被 Git 忽略。可以设置 `PORT`、`HOST`、`LAN_DATA_DIR`、`LAN_QUOTA_BYTES`、`LAN_RESERVE_BYTES` 和 `LAN_GRACE_MS`。默认临时文件额度为 50GB、磁盘保留 1GB、离线保留五分钟。

```sh
node --test test/*.test.mjs
```

完整测试包含 HTTP / UDP、加密与完整性、下载、续传、好友、后台生命周期及多网卡选择。Windows 专属测试需要相应系统环境；单机自动测试不代表所有物理设备组合均已验收。
